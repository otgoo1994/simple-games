# Read me

## 1. Install Nodejs 20+

1. Download nodejs from `https://nodejs.org/en/download`

--- 

## 2. Install project


1. Clone this repo
2. `npm install` to install all the dependencies defined in a `package.json` file

---


## 3. gitlab commit rules

1. Keywords

    - feat: If you added new feature
    - fix: If you fixed old feature
    - style: If you change only stylesheet
    - docs: If you add document file

2. Please select the action type and enter your character.
3. Please enter your characters english only.

4. Example git commit

    - feat: added translator and notification component.
    - fix: restore notification component rules.
    - style: remove notification padding.
    - docs: README commit
